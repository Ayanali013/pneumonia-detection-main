# Project Documentation

This folder contains the project documentation for the current working version of the Pneumonia Detection project.

## Contents

- [technical-documentation.md](./technical-documentation.md): project overview, requirements, architecture, workflows, and implementation details.
- [project-report-draft.md](./project-report-draft.md): draft report prepared for Integral University B.Tech Semester VII submission format, covering Preliminary Pages and Chapters 1 to 4.
- [university-forms.md](./university-forms.md): editable drafts for the required university project forms and progress-report content.
- [screenshot-checklist.md](./screenshot-checklist.md): checklist of screenshots to capture for the final report.

## Scope and status

- The documents are based on the actual implementation found in the current workspace.
- Where academic or institutional details are not available, placeholders are clearly marked.
- No fake student names, signatures, or official approvals are included.
- The application is a working prototype for local demo and educational use, not a production clinical system.
