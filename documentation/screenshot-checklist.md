# Screenshot Checklist for Final Report

Use these screenshots only if they match the actual running application and were captured from the current local workspace.

## Required screenshots

1. Home page / landing page
2. Upload panel with chest X-ray image
3. Result panel with probability estimate
4. Sidebar showing model selection and labels
5. Error message for invalid file or unsupported image
6. Output screen for pneumonia detection result
7. Result screen for normal case
8. Any training/evaluation-related script output captured from CLI
9. App running locally (browser or local server view)

## Additional optional screenshots

- training script execution log
- evaluation script output
- dataset inspection summary from Python shell
- architecture / workflow figure if used in final documentation

## Important notes

- Only use genuine screenshots from the running application.
- Do not fabricate UI output or image results.
- For final report submission, capture screenshots after confirming the current app is working.
- Keep date, version, and environment notes if the institution expects them.
